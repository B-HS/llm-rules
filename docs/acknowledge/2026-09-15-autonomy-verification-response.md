# 자율 Git·검증 예산·응답 계약 결정

## 결정

- 일반 commit·push의 llm-rules 승인·차단 hook을 제거하고 플랫폼 권한은 무조건 허용합니다.
- Force push는 파괴적 작업으로 분리해 금지 또는 사전 확인 정책을 유지합니다.
- 표시상 상위 작업 하나만 진행 중으로 두되 독립 하위 작업은 병렬 실행합니다.
- 관련 입력·환경이 바뀌지 않은 성공 검증은 재실행하지 않습니다. 실패 원인에 영향을 준 수정 뒤에는 해당 검사만 한 번 재실행합니다.
- 애매한 보조 검증은 Codex Luna xhigh, Claude Code Haiku xhigh에 배정합니다. 지나치게 특수한 엣지케이스는 `docs/quality-assurance`에 테스트 부채로 기록합니다.
- 응답은 첫 줄의 실행 행동 또는 답, 한 줄 상태, 최소 번호 단계, 구체적 결과와 남은 경우 하나의 다음 행동을 중심으로 작성합니다.

## 적용 범위

공통 컨벤션 코어, Codex Subagent workflow, Claude Code workflow·Output Style, 설치기와 배포 문서에 적용합니다.

## 충돌 해석

- `진행 중 하나`는 사용자에게 표시하는 상위 상태를 뜻하며 실제 독립 작업의 병렬 실행을 제한하지 않습니다.
- 중복 검증 금지는 변하지 않은 성공 결과에 적용하며 실패 수정 후의 영향 범위 재검증은 허용합니다.
- 시스템·개발자·실행환경 제약은 이 저장소 규칙보다 우선하므로 호스트가 요구하는 승인을 우회한다고 보장하지 않습니다.
