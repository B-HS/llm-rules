# PROCESS 관리

1. `docs/` 가 없으면 만들고 `docs/PROCESS.md` 를 읽습니다. 대화와 파일이 다르면 파일을 기준으로 삼습니다.
2. 진행 중인 작업의 완료 항목을 `[x]` 로 바꾸고, 항목마다 한 일이나 다음 할 일을 한 줄 적습니다.
3. 새 작업이면 아래 형식으로 섹션을 추가합니다.

```markdown
## 작업: <작업명> (진행 중)

<요청 한두 줄 요약>

- [ ] 1. <할 일> — <상세·참조>

기준 문서: <이 작업이 따르는 문서나 결정 기록>
```

4. 요청 범위 안에서 완료에 필요한 항목이 생기면 추가하고 계속 진행합니다. 요청 범위를 넓히는 항목은 추가하지 않고 사용자에게 묻습니다.
5. 작업이 끝나면 제목의 `(진행 중)` 을 `(완료)` 로 바꿉니다. `PROCESS.md` 가 약 300줄을 넘으면 오래된 완료 섹션을 `docs/history/` 로 옮깁니다.

완료 수와 전체 수, 다음 항목을 한 줄로 보고합니다.
