# 피드백 기록

실제 사용자 발언에 근거한 교정만 기록합니다.

1. 사용자가 지정한 지적이 있으면 그것을, 없으면 이번 세션의 반려·교정·재작업 요청을 수집합니다.
2. 지적 1건마다 `docs/feedback/YYYY-MM-DD-<짧은-슬러그>.md` 파일 하나를 사용합니다.
3. 무엇을 지적받았는지, 왜 틀렸는지, 어떻게 고치는지, 언제 적용하는지를 적습니다.
4. 항상 적용할 보편 규칙이면 `docs/convention` 또는 `docs/memory` 승격 후보와 이유를 표시합니다. 승격 자체는 사용자 확인 없이 수행하지 않습니다.

추측한 교훈이나 사용자 발언에 없는 정책을 만들지 않습니다. 작성 경로와 승격 후보 여부를 보고합니다.
